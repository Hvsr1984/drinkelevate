# ELEVATE — Premium Drinking Water

ELEVATE is a premium luxury drinking water brand page. Sourced from the heart of the Himalayas, this application provides an immersive showcase of pure, sparkling, mineral-enriched, and alkaline water offerings.

## Technology Stack

This application is built with modern frontend tools:

- **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/) (Radix Primitives)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Features

- **Dynamic Interactive UI**: Liquid animations, wave dividers, and custom water bubble background effects.
- **Product Showcase**: Detailed pages for each water type highlighting source details, pH balance, and mineral configurations.
- **Purity & Quality Transparency**: An interactive report displaying lab certification parameters, mineral profiles, and batch testing histories.
- **Shopping Interface**: Responsive cart drawer for selecting bottle quantities and checking out.

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Install all dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build the project for production:
   ```bash
   npm run build
   ```
